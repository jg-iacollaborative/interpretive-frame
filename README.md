# interpretive-frame
Three skills intended to help LLM-assisted synthesis use context to make outputs more insightful and actionable

 Skill | What it does | Input | Output |
|---|---|---|---|
| **evidence-to-insight** | Distills research into evidenced needs, then sharp insights about human motivation | Transcripts, session notes, survey verbatims (optionally early hypotheses) | Needs spreadsheet and insights document |
| **insight-to-action** | Turns insights into guiding principles for a specific organization | Insights and organizational context | Guiding principles with insights nested underneath |
| **run-interpretive-frame** | Runs the two skills above in order | A mixed batch of documents | Needs, insights, and principles together |
